# Changelog

## fmggp2 0.2.0

- New
  [`theme_gameboy()`](https://mjfrigaard.github.io/fmggp2/reference/theme_gameboy.md):
  the original Game Boy screen palette with the bundled Press Start 2P
  pixel font.

## fmggp2 0.1.0

- [`theme_win98()`](https://mjfrigaard.github.io/fmggp2/reference/theme_win98.md)
  and
  [`theme_napster()`](https://mjfrigaard.github.io/fmggp2/reference/theme_napster.md)
  late 90s themes.
- Book helpers
  [`co_box()`](https://mjfrigaard.github.io/fmggp2/reference/co_box.md),
  [`status()`](https://mjfrigaard.github.io/fmggp2/reference/status.md),
  and `%nin%`.
- README, Quarto vignettes, and pkgdown site.
